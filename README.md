
# MVP - Espaço Di Iorio

## Descrição do projeto

Este projeto tem como objetivo desenvolver um MVP para auxiliar na administração do Espaço Di Iorio, um espaço destinado à locação para lazer e eventos.

## Objetivo

Facilitar o cadastro de clientes, o registro de reservas e a consulta de disponibilidade de datas.

## Funcionalidades iniciais

- Cadastro de clientes.
- Registro de reservas.
- Seleção do tipo de locação: Day Use ou pernoite.
- Listagem das reservas cadastradas.
- Verificação básica de reservas para a mesma data.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Público-alvo

## Como executar o projeto

1. Acesse o arquivo index.html no repositório.
2. Baixe o arquivo para o computador.
3. Abra o arquivo em um navegador, como Google Chrome.
4. Preencha os dados do cliente e registre uma reserva para testar as funcionalidades.

Observação: os dados cadastrados não ficam salvos após fechar ou atualizar a página.

## Observação

Esta é uma versão inicial e demonstrativa do MVP. Os dados são mantidos apenas durante a utilização da página, sem armazenamento permanente em banco de dados.
